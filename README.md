## 📂 Folder Structure

The workspace contains three folders, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies
- `res`: the folder holding project resources
- `font`: the folder containing project fonts
- `img`: the folder containing resources for UI
- `figma`: the folder containing self-made design within figma
- `icons`: the folder containing Google Fonts Icons
- `user`: the folder containing user data (locally)
